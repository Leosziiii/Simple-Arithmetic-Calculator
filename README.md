# Simple Arithmetic Calculator

A simple arithmetic calculator built using **C++**. This project allows users to perform basic mathematical operations through a console-based program.

Created as a beginner project to practice C++ programming fundamentals and improve problem-solving skills.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* User input for numbers and operations

## Technologies Used

* C++
* Standard Input/Output (`iostream`)

## Example

```text
Simple Arithmetic Calculator

Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 5

Result: 15
```

## Purpose

This project was created to practice basic C++ concepts, including:

* Variables and data types
* User input and output
* Arithmetic operators
* Conditional statements
* Basic program logic
